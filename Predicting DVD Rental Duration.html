Project Title: Predicting DVD Rental Duration for Inventory Optimization¶

A DVD rental company wants to predict how many days a customer will keep a DVD. Accurate predictions enable better inventory planning, reduce stock-outs, and improve customer satisfaction. Success criterion: Mean Squared Error (MSE) ≤ 3 on an unseen test set. Target variable: rental_length_days (derived from return date − rental date).

# Outlier detection (IQR method)
def count_outliers(series):
    Q1, Q3 = series.quantile([0.25, 0.75])
    IQR = Q3 - Q1
    return ((series < Q1 - 1.5*IQR) | (series > Q3 + 1.5*IQR)).sum()

for col in ['amount', 'length', 'replacement_cost', 'rental_length_days']:

#Modeling
models = {
    'Linear Regression': LinearRegression(),
    'Ridge': Ridge(alpha=1.0, random_state=9),
    'Lasso': Lasso(alpha=0.1, random_state=9),
    'Random Forest': RandomForestRegressor(n_estimators=100, random_state=9, n_jobs=-1),
    'Gradient Boosting': GradientBoostingRegressor(n_estimators=100, random_state=9)
}

results = {}
for name, model in models.items():
    model.fit(X_train, y_train)
    y_pred = model.predict(X_test)
    results[name] = {
        'MSE': mean_squared_error(y_test, y_pred),
        'RMSE': np.sqrt(mean_squared_error(y_test, y_pred)),
        'MAE': mean_absolute_error(y_test, y_pred),
        'R2': r2_score(y_test, y_pred)
    }

results_df = pd.DataFrame(results).T.round(4)
print(results_df.sort_values('MSE'))

The results show that Linear models explain ~59% of the variance — decent but limited by the non-linear relationship between final amount paid and duration. Random Forest captures interactions and non-linearities, achieving 71% explained variance and reducing the average absolute error to ~1.1 days, making it a better model.

From the results, amount appears to be the most dominant driver; this implies that customers who end up paying more generally kept the DVD longer than others. Base rental_rate has a negative coefficient, indicating that higher-rate titles are returned slightly sooner on average. Special features and rating dummies have small effects.

Business Recommendations¶

  1. The management should Deploy the Random Forest model for daily inventory forecasting. The expected average error is ~1.1 days.
  2. Use predicted duration to set dynamic safety stock levels by title popularity and predicted hold time.
  3. Monitor amount at return deployment — large deviations from expected duration can flag potential late fees or customer issues.
  4. Consider simplifying features in production: keep amount, rental_rate, replacement_cost, and a few rating/special-feature flags if latency or interpretability becomes important.
  5. On the next iteration: add customer-level history that is the previous average rental length, and time-of-week effects for further gains.
